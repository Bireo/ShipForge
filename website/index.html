核心功能

多框架识别与前置自检

自动识别 Rust、Node/TS、Python、Go、.NET、Flutter、C++、Java 与常见打包外壳，按需检查编译器与本地依赖，确认后再补全。

体积分析与安全分包

扫描项目体积分布和大文件，默认拦截 .env、私钥和 .git，支持按仓库单文件大小限制切分分卷并附校验清单。

多配置版本原子同步

统一同步 Cargo.toml、tauri.conf.json、package.json、pyproject.toml 等版本源，自动读取或回写变更记录。

多平台原生流式发布

基于 WinHTTP 直接上传至 GitHub、Gitee、GitLab、Gitea，令牌使用 Windows DPAPI 加密保存，支持线上编辑与撤回。

事务回滚与成品保护

构建或发布中途失败、取消时自动回滚未完成的版本与本地提交；已验收成品支持免重编直接补传发布。

内置自动更新

支持安装版与便携版在线检测 GitHub Releases 新版本，强制核验 SHA-256 与文件头，便携版更新失败自动回滚旧版。

本地构建与推送更新

git clone https://github.com/3347567186/ShipForge.git
cd ShipForge
pwsh -NoProfile -ExecutionPolicy Bypass -File .\build.ps1 -Bump patch
pwsh -NoProfile -ExecutionPolicy Bypass -File .\tools\publish-release.ps1 -UploadGitHub
