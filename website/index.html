RELEASE PIPELINE

一条可控的本地发版流水线

从代码改动到远端 Release 资产上线，每个阶段都有前置检查与失败回滚保护。

  1. 01

    识别与对账

    解析语言、外壳、构建脚本与多文件版本号，同时兼容 Git 与非 Git 目录指纹监控。

  2. 02

    前置自检

    仅核验当前项目所需工具链、本地依赖与磁盘余量，展示变更清单经确认后再补全。

  3. 03

    构建与分包

    实时终端捕获构建日志，自动拦截 .env / 私钥等敏感文件，支持大包按平台阈值分卷。

  4. 04

    校验与清单

    并行计算 SHA-256、生成 latest.json 与 SHA256SUMS.txt，校验版本对齐与文件完整性。

  5. 05

    原子推送

    WinHTTP 流式上传至目标仓库，二进制优先、清单最后落盘；异常中断时保护已验收成品。

WORKBENCH MODULES

面向日常高频场景的核心模块

界面保持克制与低干扰，每个功能只保留单一清晰入口。点击任意截图可展开高清检视。

01 · PREFLIGHT & PRESETS

项目级前置自检，不盲装无关工具

按「语言 × 打包壳 × 子引擎」自动筛选当前项目真正依赖的编译器（MSVC / MinGW / rust-lld / NSIS / Node / Python 等），展示安装路径与体积并在确认后执行修复。

  • 支持 8 种主流开发语言与 Tauri / Electron / Wails / NSIS 等打包外壳
  • 自动内省本地 build.ps1 参数，保留自定义构建与测试工序
02 · ANALYZE & SPLIT

打包前看清体积分布，默认拦截敏感文件

扫描项目有效体积、按类型统计占比并列出 Top 大文件；发现 .env、私钥、证书或 .git 目录时主动预警并一键加入排除规则，支持按平台单文件限制自动分卷。

  • 自动跳过 target / node_modules / .git 缓存目录，避免误统计
  • 保存常用分包预设（便携 ZIP / tar.gz / 95 MB 兼容分卷）
03 · MULTI-REPO RELEASE

原生直连多代码平台，令牌系统级加密

内置 GitHub、Gitee、GitLab 与 Gitea 原生适配器，支持左侧浏览历史线上版本、右侧一键创建或编辑 Release、切换草稿状态、撤回版本或删除单个附件。

  • 访问令牌经 Windows DPAPI 加密存储，本地零明文落盘
  • 发布前自动核验 latest.json 哈希与版本号，拦截残缺清单
04 · VERSIONING & AUTO-UPDATER

原子版本同步与内置官方自动更新

双栏变更日志自动识别升序/降序结构回写 CHANGELOG，多配置文件原子同步版本号。同时 ShipForge 自身内置基于 GitHub Releases 的三通道容错自动更新，支持断点续传与失败自动回滚。

  • 同时覆盖 NSIS 安装版与便携 ZIP 版更新形态，强制校验 SHA-256 与文件头
  • 存在运行中构建/发版任务时拒绝中断安装，保障项目事务安全
