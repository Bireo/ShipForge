# ShipForge 发包与在线更新指南

本文说明如何使用内置脚本为 ShipForge 构建新版本、生成 `latest.json` 更新清单，并向 GitHub Releases 或自建回环测试源推送更新。

## 1. 本地全量构建

```powershell
# 递增版本号（patch / minor / major）并执行完整门禁与打包
pwsh -NoProfile -ExecutionPolicy Bypass -File .\build.ps1 -Bump patch
```

构建完成后会在 `release\` 生成以下产物：

- `ShipForge_<ver>_x64-setup.exe`（NSIS 安装包）
- `ShipForge_<ver>_x64-portable.zip`（免安装便携包）
- `SHA256SUMS.txt`（SHA-256 摘要表）
- `latest.json`（标准在线更新清单）

## 2. 推送到 GitHub Releases（原子发布）

需提前安装并登录 GitHub CLI（`gh auth login`）：

```powershell
# 正式版发布
pwsh -NoProfile -ExecutionPolicy Bypass -File .\tools\publish-release.ps1 -UploadGitHub

# Beta 预发布通道
pwsh -NoProfile -ExecutionPolicy Bypass -File .\tools\publish-release.ps1 -Channel beta -UploadGitHub

# 覆盖同版本已存在的 Release 资产
pwsh -NoProfile -ExecutionPolicy Bypass -File .\tools\publish-release.ps1 -UploadGitHub -Clobber
```

脚本上传前会自动校验二进制魔数（`MZ` / `PK\x03\x04`）和体积下限；新建 Release 时采用 `--draft` 先传安装包、便携包与 `SHA256SUMS.txt`，随后串行上传 `latest.json`，最后解除草稿态，避免客户端在上传窗口期拉到 404 资产。

## 3. 本机回环端到端测试更新

ShipForge 更新客户端默认只信任 `github.com/Bireo/ShipForge`、`api.github.com/repos/Bireo/ShipForge` 与 GitHub 官方下载 CDN。本机调试时可通过 `SHIPFORGE_UPDATE_FEED` 指定回环地址（仅放行 `127.0.0.1` / `localhost` / `::1`）：

```powershell
# 终端 1：启动本地回环更新源（支持 Range 断点续传）
pwsh -NoProfile -ExecutionPolicy Bypass -File .\tools\publish-release.ps1 -ServeLocal -Port 18765

# 终端 2：指向本地源启动旧版 ShipForge
$env:SHIPFORGE_UPDATE_FEED = "http://127.0.0.1:18765/latest.json"
.\shipforge.exe
```

在软件内打开「偏好设置 → 版本与更新」点击「检查更新」，即可完整验证检测、断点续传、SHA-256 校验与安装/便携原子替换回滚流程。
